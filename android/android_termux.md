# Termux

## Install command-line tools

```shell
$ pkg install aria2 bash-completion curl ffmpeg grep gzip htop imagemagick \
    less man mc nano p7zip python sox termux-api unzip wget zip
```

## Configuration paths

Termux stores its system-wide configuration under:

```text
/data/data/com.termux/files/usr/etc/
```

OpenSSH host keys are normally stored under:

```text
/data/data/com.termux/files/usr/etc/ssh/
```
