# Blood con NotBlood

Ejecutable local: `~/src/NotBlood/notblood`

## Directorio de datos

Los datos de Blood están instalados en `~/games/nblood`. NotBlood resuelve
los archivos del juego relativamente al directorio actual, por lo que se
debe iniciar desde allí.

## Juego original

```shell
$ cd ~/games/nblood && ~/src/NotBlood/notblood
```

## Cryptic Passage

```shell
$ cd ~/games/nblood && ~/src/NotBlood/notblood -ini cryptic.ini
```

La configuración personal se guarda en:

```text
~/.config/notblood/notblood.cfg
~/.config/notblood/notblood_cvars.cfg
```
