# Shadow Warrior con VoidSW

Ejecutable local: `~/src/eduke32/voidsw`

Instalar o actualizar en Devuan:

```shell
~/src/scripts/devuan/games/install_voidsw.sh
```

```shell
~/src/eduke32/voidsw -game_dir ~/games/emu/dos/fps/swarrior
```

Raze es una alternativa moderna que usa el mismo directorio de datos.
