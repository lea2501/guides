# Rise of the Triad con ROTTEXPR

Ejecutable principal: `~/src/rottexpr/src/rottexpr`

Instalar o actualizar las cuatro variantes en Devuan:

```shell
~/src/scripts/devuan/games/install_rottexpr.sh
```

ROTTEXPR busca los datos en el directorio de trabajo, por lo que se inicia así:

```shell
cd ~/games/emu/dos/fps/rtriaddw && ~/src/rottexpr/src/rottexpr-site-license
```

También quedan disponibles:

```text
~/src/rottexpr/src/rottexpr
~/src/rottexpr/src/rottexpr-shareware
~/src/rottexpr/src/rottexpr-superrott
~/src/rottexpr/src/rottexpr-site-license
```

Los packs adicionales de `rtriadae` y `rtriadwp` deben instalarse o cargarse
sobre una copia compatible de Dark War; no son juegos independientes.

Proyecto: `https://github.com/LTCHIPS/rottexpr`
