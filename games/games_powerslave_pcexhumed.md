# PowerSlave con PCExhumed

Ejecutable local: `~/src/NBlood/pcexhumed`

PCExhumed se compila junto con NBlood y Rednukem:

```shell
~/src/scripts/devuan/games/install_nblood.sh
```

```shell
~/src/NBlood/pcexhumed -game_dir ~/games/emu/dos/fps/pslave
```

Como alternativa moderna puede usarse `~/src/Raze/build/raze` con el mismo
directorio de datos.
