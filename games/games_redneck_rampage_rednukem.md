# Redneck Rampage con Rednukem

Ejecutable local: `~/src/NBlood/rednukem`

Rednukem se compila junto con NBlood y PCExhumed:

```shell
~/src/scripts/devuan/games/install_nblood.sh
```

## Redneck Rampage

```shell
~/src/NBlood/rednukem -game_dir ~/games/emu/dos/fps/rrampage
```

## Redneck Rampage Rides Again

```shell
~/src/NBlood/rednukem -game_dir ~/games/emu/dos/fps/rramprr
```

Raze es una alternativa para ambos juegos.
